### ⚡ About

Software Engineer & Solution Architect at **QVC Group (Qurate Retail Group)**, working on the merchandising platform out of Germany. I design **event-driven Java/Spring Boot microservices** (Kafka, IBM MQ) on **Azure**, and increasingly build **production GenAI systems** — multi-agent orchestration, MCP servers, and RAG over graph data.

- 🏗️ Currently: agent harnesses, MCP tooling, and approval-gated autonomous ops
- 🧠 8+ years across **retail, FX/fintech (360T · Deutsche Börse), supply chain (Manhattan Associates)** and **telecom R&D (Nokia)**
- 🎓 M.Sc. Global Software Development · Anthropic & Hugging Face certified
- 🌍 India → Germany
